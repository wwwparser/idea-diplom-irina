# Проверка биллинга через Browser Bridge, 18 октября 2026

Проверка выполнена в живой авторизованной сессии Chrome, отдельная сессия моста `diplom-irina`. Привязка облака и платёжные настройки не изменялись.

Организация: `organization-limellis`, `bpf9409c557i9h5igprs`.
Облако: `cloud-limellis`, `b1gb7ghs6e3j9crn0t19`.

Штатные запросы, отправленные самой консолью при открытии облака:

| Запрос браузерной консоли | Ответ |
|---|---|
| `billing/hasBillingAccount`, облако `b1gb7ghs6e3j9crn0t19` | HTTP 200, `hasBillingAccount: true` |
| `billing/getBillableEntityBillingAccount`, то же облако | HTTP 200, `id: dn2lfesvcam5jmpa602k` |
| `billing/getAccountWithBlock`, этот аккаунт | HTTP 403, `AuthorizationError`, «Доступ запрещён» |

Прямое открытие страницы `https://center.yandex.cloud/billing/accounts/dn2lfesvcam5jmpa602k/overview` подтверждает выбранную организацию `organization-limellis`, но показывает отсутствие прав на просмотр раздела.

**Вывод:** облако уже привязано. Повторная привязка и пополнение личного account-203 не требуются на основании этой проверки. Статус активности, деньги и грант целевого аккаунта проверить с текущими правами невозможно. Требуется подтверждение владельца либо доступ на просмотр его платёжного аккаунта. Квоты облака остаются отдельным ограничением для нового стенда.

Для открытия консоли временно добавлялись исключения системного прокси только для доменов Yandex Cloud: прямое соединение работало, прокси давал ошибки TLS/ERR_CONNECTION_CLOSED. После проверки добавленные исключения удалены; сторонние настройки сохранены. Скриншот раздела с отказом доступа находится локально в игнорируемом `.local/billing-account-check-20261018.png`.

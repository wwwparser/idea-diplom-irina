## Возобновление

`scripts/prepare_cloud.py` проверяет соответствие организации/облака, создаёт либо находит отдельный каталог, готовит параметры и проверяет привязку биллинга. Для REST вызовов используется отдельный `src/services/yandex_client.py` с timeout, retry чтения и без вывода токенов. Подготовка не выполняет привязку биллинга и не создаёт платных ресурсов.

После снятия блокировок: свежий IAM token → повторный preflight/квоты → новый Terraform plan → apply → доверенная проверка SSH host keys → inventory для WSL → Ansible → настройка Zabbix/Kibana и функциональные проверки по ACCEPTANCE.md.

## Учебные HTTPS-сертификаты

Домен для UI не предоставлен. Использованы самоподписанные сертификаты с SAN фактических публичных IP, сроком 90 дней. Браузер не доверяет им автоматически. Можно импортировать именно приложенные публичные сертификаты либо проверить их отпечатки перед добавлением исключения для этих адресов. Закрытые ключи остаются на ВМ.

| Интерфейс | Сертификат | SHA-256 DER |
|---|---|---|
| Zabbix | [zabbix.crt](certs/zabbix.crt) | `cea77493436e9ff503460f7cf106cdbac13b0fcfd5b94d89001c10153c315f48` |
| Kibana | [kibana.crt](certs/kibana.crt) | `aad9dab41b29de360f58cd06969db695395cc3084127fdaa0802f9818eb19731` |

Проверка без отключения TLS validation:

```bash
curl --cacert docs/certs/zabbix.crt https://158.160.239.100/
curl --cacert docs/certs/kibana.crt https://153.51.118.76/
openssl x509 -in docs/certs/zabbix.crt -noout -fingerprint -sha256
```

Автоматическая проверка обоих публичных HTTPS-интерфейсов, доверенных сертификатов и входа reviewer: [public-ui.json](../evidence/public-ui.json). При повторном развёртывании сертификаты и адреса могут измениться: нужно заново выполнить `scripts/verify_ui.py` и обновить ссылки.

## Что посмотреть

В Zabbix открыть dashboard Irina — USE infrastructure. Вкладки соответствуют шести ВМ. На web-страницах ниже находятся HTTP-графики; красная пунктирная линия — порог. В Latest data можно проверить свежесть данных. Стандартный индикатор доступности пассивного интерфейса может показывать Unknown: агенты используют активные проверки, фактическая работа подтверждается обновлением items.

В Kibana открыть dashboard Irina — nginx access and error logs. Верхняя панель показывает access.log, нижняя — error.log. В колонке host.name представлены irina-web-a и irina-web-b. Временной диапазон — последние сутки; новые события можно получить кнопкой Refresh.

## Для владельца

Реальные пароли находятся в игнорируемом `.local/service-credentials.json`; значения `reviewer_password`, `zabbix_admin_password` и `elastic_password` различаются. В Ansible используются зашифрованные Vault vars. Не включать эти файлы или ключи в сообщение руководителю вместе с репозиторием. Проверяющему достаточно одного пароля reviewer.

Для локального административного доступа: `python scripts/tunnels.py`. Zabbix доступен на `http://127.0.0.1:18080`, Kibana — `http://127.0.0.1:15601`, Elasticsearch — `http://127.0.0.1:19200`. Этот HTTP идёт внутри SSH-туннеля. Завершение процесса закрывает туннели.
